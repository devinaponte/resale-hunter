# Resale Hunter Mobile

Phone-friendly Streamlit version.

## Improvements
- centered mobile layout
- large tap targets
- stacked deal cards
- collapsible alert settings
- compact summary metrics
- individual expandable listing details
- simple "test your own deal" form

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

For true iPhone use, deploy this folder to a Streamlit-compatible host and open the resulting URL in Safari.
